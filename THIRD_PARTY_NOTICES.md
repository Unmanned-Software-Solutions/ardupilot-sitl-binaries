This repository builds ArduPilot SITL binaries and publishes them as GitHub Releases. This file lists the
third-party code in those release archives, the licences it is under, and where the licence texts are. The
licence texts are in `LICENSES/`. The licences of this repository's own files are in "License" in `README.md`.

## Cygwin runtime (Windows archives)

- Shipped as: the `bin/cyg*.dll` files in each `windows-x64` archive, next to the binary. They are unmodified copies
  of the DLLs that `cygcheck` lists for the binary, taken from the Cygwin installation the binary is built with.
  GCC is pinned to Cygwin package `gcc-g++ 13.4.0-1` in `.github/workflows/build-sitl.yml`. The other packages are
  the version the Cygwin mirror served on the day of the build; for example, `ardupilot-sitl-Tracker-4.6.2-windows-x64.zip`
  holds `cygwin1.dll` from `cygwin 3.6.9-1`.
- Each DLL is a separate library that the binary loads when it starts; you can replace a DLL with another build of
  the same library.

## Written offer for source code

For at least three years after Unmanned Software Solutions Sp. z o.o. last publishes a release archive in this
repository, it will give any third party, on request, a complete machine-readable copy of the corresponding source
code of the ArduPilot SITL binary and the Cygwin libraries in that archive, on a medium customarily used for software
interchange or as a download, for a charge no more than the cost of physically performing the source distribution.
Send the request, naming the release and the archive, to info@unmnds.com. The ArduPilot source is also published at
the tag named by the release.
